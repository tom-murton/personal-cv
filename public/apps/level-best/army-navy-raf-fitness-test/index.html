Armed forces bleep test standards (RAF, Army, Navy)

The forces use the 20m multi-stage fitness test at officer selection, but the standards vary by service and role, and some entry routes have changed recently.

RouteStandardNotes
RAF Officer (Cranwell)20m 9.10Age and sex banded; 9.10 is the 17–24 male green standard.
Army Officer20m 10.2Officer selection. Note: soldier entry moved to a 2km run in Nov 2025.

Read this before you train: British Army soldier entry replaced the bleep test with a 2km run in November 2025, officers still run the MSFT. Royal Navy ratings use a 2.4km treadmill run. Always confirm the current test for your specific route.
